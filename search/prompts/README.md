# Prompt templates

These text files are optional inputs for LLM-based creation and structural
refinement. They describe the expected response format and constraints for
the typed skill DSL. They are not required for exact paper reanalysis or
archived replay.

A live run should record the template name and a hash of the template used,
without storing credentials. Public semantic-study templates use the neutral
context policy defined in `search/semantic_context_policy.py`.
