# Documentation

This folder contains public installation, protocol, data, and troubleshooting
notes for the reproducibility archive.

- [`INSTALLATION.md`](INSTALLATION.md): Conda setup, verification, and
  headless rendering.
- [`PROTOCOL.md`](PROTOCOL.md): the reported evaluation contract and the three
  reproducibility tiers.
- [`LLM.md`](LLM.md): environment-only API setup, privacy, costs, and
  deterministic dry-runs.
- [`DATA_FORMATS.md`](DATA_FORMATS.md): record, metric, and output semantics.
- [`PAPER_CROSSWALK.md`](PAPER_CROSSWALK.md): mapping from paper claims to
  archived records and commands once the catalog is materialized.
- [`TROUBLESHOOTING.md`](TROUBLESHOOTING.md): common installation and runtime
  failures.
