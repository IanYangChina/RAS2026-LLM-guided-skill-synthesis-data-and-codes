# Provenance

Source hashes, normalization declaration, exclusions, and public checksums. Original private paths and revision identifiers are not distributed.

`winner_extractions.csv` binds every run-log-extracted selected skill to its
container hash, entry index/iteration, YAML field, superseded top-level hash,
and selected embedded hash. `reconstructed_scene_banks.csv` documents the 540
lossless frozen-state reconstructions without claiming source-byte identity.
`derived_records.csv` records the evidence and derivation for all 1,380
parameter maps and 1,380 normalized cell records.
