# Simulation assets

This directory contains the MuJoCo robot, gripper, and task-object models
needed by the public scenes. Asset files are data and are loaded by the scene
builder; they are not Python modules.

Keep each upstream README and LICENSE beside its model. The repository-level
[`THIRD_PARTY_NOTICES.md`](../../THIRD_PARTY_NOTICES.md) records the principal
MuJoCo and Franka sources. Check asset-specific notices before redistributing a
modified model.
